# JavaScript闭环数据导致死循环案例

## 问题类型

路径算法异常循环。

## 场景

业务需要根据旅游行程段自动拼接完整路线。

当数据存在闭环：

```
A → B
B → C
C → A
```

如果没有循环检测，会持续寻找下一段路线。

## 排查过程

检查方向：

1. 是否存在递归无出口
2. while循环是否有退出条件
3. 节点是否重复访问
4. 行程段是否重复使用

## 修复原则

不要只修当前数据，需要增加算法防御：

- 节点访问记录
- 边使用记录
- 最大迭代次数

## 复用经验

所有图结构、链路生成、依赖分析场景，都需要考虑环路问题。
