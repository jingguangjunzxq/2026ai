# buildTripPaths设计说明

## 1. 功能说明

根据行程段数据构建城市路径。

输入包含：

- startCity
- endCity
- startMs
- endMs

输出：

```javascript
{
  starts: [],
  ends: [],
  paths: {}
}
```

## 2. 核心流程

```
原始行程
 ↓
时间排序
 ↓
建立城市索引
 ↓
寻找下一节点
 ↓
生成路径链
 ↓
闭环检测
 ↓
输出结果
```

## 3. 关键设计

### 城市索引

使用 Map 建立出发城市索引，减少重复扫描。

```javascript
cityIndex.get(city)
```

### 防环控制

路径生成过程中维护：

- usedTrips：已经使用的行程段
- visitedCities：已经访问的城市

### 多链支持

例如：

```
北京→东京→大阪
上海→首尔→釜山
```

输出：

```javascript
{
 北京:[北京,东京,大阪],
 上海:[上海,首尔,釜山]
}
```
